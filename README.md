# Zap-oramento
Gerador descomplicado e gratuito de orçamentos e recibos para autônomos e MEIs, com cálculo automático e envio formatado via WhatsApp.
# ⚡ ZapOrçamento

Uma ferramenta web prática, leve e gratuita desenvolvida para ajudar microempreendedores individuais (MEIs) e profissionais autónomos a criarem orçamentos e recibos profissionais em segundos.

## 🚀 Funcionalidades
- **Gravação automática:** Nome do prestador e chave PIX ficam guardados localmente no navegador (`localStorage`).
- **Cálculo automático:** Soma dos valores de múltiplos serviços em tempo real.
- **Envio direto por WhatsApp:** Gera um texto estruturado e abre a conversa com o cliente num clique.
- **Exportação em PDF:** Formatação limpa pronta para guardar em PDF ou imprimir.
- **Compatível com telemóvel e computador:** Funciona em qualquer ecrã sem necessidade de instalar aplicações.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica da aplicação.
- **CSS3:** Interface em modo escuro (*Dark Mode*) e estilização para impressão.
- **JavaScript:** Lógica de cálculo, manipulação dinâmica e armazenamento local.
