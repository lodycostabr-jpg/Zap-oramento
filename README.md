## 📱 Destaques do Projeto

- **📲 Instalação como App Nativo (PWA):** Suporte a `Service Worker` e `manifest.json`, permitindo instalar o ícone na tela inicial do celular sem lojas de app.
- **🛡️ Validação Algorítmica de CPF:** Checagem em tempo real dos dígitos verificadores da Receita Federal com feedback visual imediato.
- **🔊 Feedback Sonoro Dinâmico:** Sons de confirmação harmônica e alertas sintetizados nativamente via **Web Audio API** (sem necessidade de carregar arquivos MP3 externos).
- **📜 Histórico Local Inteligente:** Salva até 25 orçamentos no `localStorage` do dispositivo para consulta, reenvio ou exclusão rápida.
- **🖼️ Suporte a Logotipo:** Permite carregar a identidade visual do profissional diretamente na proposta.
- **💬 Envio Estruturado via WhatsApp:** Formatação automática com quebras de linha e emojis, pronta para envio com apenas um clique.
- **📄 Exportação PDF / Impressão:** Folha A4 limpa e otimizada com marca d'água de segurança.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
| :--- | :--- |
| **HTML5 Semântico** | Estruturação acessível da interface e formulários |
| **CSS3 Moderno** | Dark mode responsivo, CSS Grid, Flexbox e regras `@media print` |
| **JavaScript Vanilla** | Lógica de negócios, manipulação de DOM, cálculos e persistência |
| **Web Audio API** | Síntese de áudio para retorno interativo |
| **PWA (Progressive Web App)** | Suporte a instalação offline e comportamento standalone |

---

## 🔒 Privacidade e Segurança

Nenhum dado financeiro, de clientes ou pessoal trafega por servidores externos. Todas as informações preenchidas ficam salvas exclusivamente no armazenamento local (`localStorage`) do navegador do usuário.
